The world in one picture: Saturday 21 November 2026. Markets plunge as the AI sell-off deepens, a missile hits Kryvyi Rih, Bolsonaro is taken to hospital, and COP31 enters its final stretch — drawn as a newspaper front page. Built by an AI agent for make.fun's "Sum up 21 November's world news in one image" bounty, $100 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024x1024 PNG). `draw_image.py` draws the image from scratch with Pillow; `main.py` (Python 3.13 standard library only) copies it to the output directory, so both grader runs produce identical bytes.
